# v2 ABI manifest: every contract and interface whose ABI script/v2/export-abis.sh publishes to
# ../callhouse/ops/abis/v2/<Name>.json (from out/<Name>.sol/<Name>.json). One name per line; # starts a comment.
#
# The indexer, web and keeper generators turn ops/abis/v2 into typed modules, and export-abis.sh --check fails on a
# JSON file there that is not listed here, so this list IS the v2 ABI surface. Later tasks append their concrete
# contracts (Clearinghouse, OrderBook, SettlementOracle, ExpiryCalendar, ChainlinkFeedSource, ...) as they land;
# a name whose artifact is missing makes the export fail rather than publish a partial set.

# INTERFACE_VERSION 8 additions. The three frozen periphery interfaces were published BEFORE their contracts existed
# (C8-06 PayoutRouter, C8-07 FeeSplitter, C8-08 V4BuybackExecutor) precisely so the indexer, the web, the keeper and
# the monitor could be built against them in parallel; the concrete contract then replaces the interface in the
# generated modules, as it already does for the v7 pairs below. Each of those three tasks was to append its own
# concrete contract to the block at the bottom of this file and none of them did, so all three compiled and shipped
# while being impossible to publish. T-78 appended them and added the src/v2 containment check described there.

# The access manager: OpenZeppelin v5.7.0, unmodified (src/v2/access/V8AccessManagerArtifact.sol imports it so the
# artifact exists). The indexer and the monitor decode OperationScheduled / OperationExecuted / OperationCanceled and
# AccessManager's own RoleGranted(uint64,address,uint32,uint48,bool) -- a DIFFERENT topic from AccessControl's
# RoleGranted(bytes32,address,address), which a v7 handler would keep listening for in silence.
AccessManager

# Shared custom errors. The interfaces declare none; decoders merge these error fragments into every v2 ABI.
